# P13-ci 报告：捕获输出页的行，标题和副标题是同一个字重

方向一句话：**同一张卡里的两张列表只有一套排法——启动器分了两档，捕获输出页没分。**

## 这轮为什么让它更轻 / 更有空间感

不是加东西，是**把一行里的两句话重新排出前后**：便条行此前标题与副标题同墨同重
（浅色 113 / 113），读起来是两句等价的话；现在标题抬一档字重、副标题留在静息档，
一行里出现「主句 / 注脚」的先后——层级回到**字重与墨**上，而不是靠再加一条线。

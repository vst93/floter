# P14 · 透明材质与文字可读性

用户要求：改善深浅主题覆盖黑白页面时的可读性；滑块直接配置实际背景不透明度，给三个推荐吸附点；100% 完全不透明，重新衡量下限，终端可采用更低下限。

| Before | After | Why |
| --- | --- | --- |
| 旧低值透出过多桌面，背景与字色冲突 | 主界面 72–100%，推荐 72 / 86 / 100 | 覆盖黑白底、控件悬停及选择态；不在主题切换时改变滑块值 |
| 终端与主界面共用下限 | 终端 66–100%，推荐 66 / 83 / 100 | 画布不叠控件洗色，默认文字/光标可单独适配 |
| 最大值仍透出背景并运行模糊 | 100% 填充完全不透明，关闭原生背景效果及控件玻璃 | 避免为不可见背景继续模糊；降低后恢复所选效果 |
| 固定灰字、弱语义字色 | 对比度随实际填充与控件底色调整 | 黑白背景均检查，正文、说明与语义文字保持可读 |

设置格式及未知键保留；旧低值仍可加载，显示和渲染使用对应下限。默认主/终端均为 86%。系统高对比度模式为 86–100%，推荐 86 / 93 / 100。拖动在推荐点 ±1% 内吸附，方向键按 1% 微调。

实现：`internal/glassmap` 管范围、分层与效果；`internal/theme` 管字色；`internal/terminalui` 管画布、默认文字、工具栏与抽屉；`internal/shell` 按当前页面开关原生材质；设置文案走 `internal/i18n`。

验收：主/终端独立、范围逐值连续递增、100% 生产视图内部像素 alpha=255、页面切换恢复材质、默认文字 ≥4.5:1 / 光标 ≥3:1、ANSI 色保留、运行会话不重置字体、三档可点击/吸附、黑白底生产截图、格式化、vet 与三平台构建。全量测试与本轮前日志比较，明确记录既有失败。

测量日志：`P14-glass-readability/logs/opacity-study.log`。macOS frosted 使用既有 veil 补偿模型；检查不依赖原生模糊的对比度收益。100% 的原生效果关闭可以从调用链验证，整体 GPU/功耗收益需真机基准，不虚报数值。

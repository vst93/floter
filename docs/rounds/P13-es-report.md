# P13-es · 报告：捕获输出页的下沿补上那一格呼吸

轮号：**P13-es**｜表面：**捕获输出页**（`internal/launcher/output.go`）｜
合约：`docs/liquid-glass.md` **§6.114**｜规格：`docs/rounds/P13-es-spec.md`

## 这轮为什么让它更轻/更有空间感（一句话）

同一个页面此前**上沿有 14.4px 的页面呼吸、下沿 0**，滚到底时最后一行字离窗口边只剩 8px；
现在下沿与页头**同一格呼吸**（末尾墨离下沿 19px），窗口的下边第一次读成「这一页到此为止」
而不是「字写到了边上」。

## 量到的病（深浅同值）

| 量的是什么 | 改前 | 改后 |
|---|---|---|
| 正文分支滚到底：最后一行墨 → 窗口下沿 | **8px**（3.6 内边距 + 4.4 行尾） | **19px**（14.4 + 4.4） |
| 正文分支 `MaxY` | 685 | **695.8** |
| 正文分支静止帧（`Y=0`） | 第一行墨 y=104 | y=104（**逐字节相同**） |
| 列表分支滚到底（对照，不改） | **25px** = 6.2 + 19.8（页脚带） | 25px（不动） |

**113-4 结案**：启动器输出**列表**的下内边距垂直为 0 是**对的**——它下面那条页脚带
（`MinHeight(Space(5.5))` = 19.8）就是这一页的下呼吸，`footerMore` 不画字但**留带**。
缺带的是**正文分支**。

## 落地（产品代码 1 行 + 注释）

`output.go` 的正文分支：`Padding(0, Space(3), Space(1), Space(3))` →
`Padding(0, Space(3), header, Space(3))`。左右与顶部不动；`header` 就是这一页上沿用的那个常数。

**规矩**（写进 §6.114，此后这一族通用）：**有软边 → 软边 + 一格 `Space(2)`**（§6.113 的设置体
14.4+7.2=21.6、浮层 10.8+7.2=18.0）；**无软边 → 与页头同一格呼吸**。卡片上的滚动体不能有软边
（§6.48：半透明面上没有可回放的不透明色），所以这一支代入的是后者。

## pin 的两半

1. **值**：滚到底时最后一行的墨离窗口下沿 ≥ 页头那一格（`round(4×Spacing)` = 14）。
   改前 8 → 红，改后 19 → 绿。比较值从**出货尺**读（`designMetrics()`），不是库存字面量。
2. **归属**：多一行内容，这个距离一个像素都不许动（60 行与 61 行的读数相同）——它必须是
   **页面的内边距**，不是最后一行行尾的巧合。

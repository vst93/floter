读取为：桌面工具的参数表单与确认面，面向键盘用户，克制的轻便液态玻璃。拨盘：视觉冒险 2、动效 1、密度 6。功能契约：用户能看到当前参数、取消不执行、失败可重试；命令只消费当次提交。空间感来自及时清除过期错误与确认、保住唯一焦点，而非增加材质层。

# P13-il · 参数条件刷新与验证恢复

起点 1bf385a8，2026-11-07。意图：参数声明与运行表单在默认值、类型条件变化后，只呈现当前可提交内容的错误，并保留键盘出口。依据 P13-ik 仍待，先事件复现再落地。

设计读取：已有设置表单，面向配置本地工具的用户，轻便液态玻璃；视觉冒险度 2、动效 1、密度 6。三秒内能看到出错字段并修正，保存与运行仍由用户显式点击。

## 落地候选（以复现结果为准）

1. `internal/extensions/params.go:290`：数字默认值未参与本地声明校验 → 拒绝现有后端拒绝的数字默认值，修正后恢复保存。
2. 同处：布尔默认值未校验 → 只接受后端已有 true/false 规则。
3. 同处：选项默认值未校验 → 必须属于已有选项，保留空默认值规则。
4. `internal/settingsui/parameditor.go:182`：布尔类型隐藏占位符时焦点无出口 → 回当前类型选择，提示草稿保留。
5. `internal/settingsui/settingsui.go:7573`：已知字段拒绝未比较 Default → 默认值刷新退役过时拒绝，覆盖回调内刷新与稍后刷新两种时序。
6. `settingsui.go:7333/7570`：未知字段拒绝的整表条件未比较 Default → 默认值刷新退役过时拒绝，同样覆盖两种时序。
7. `settingsui.go:7441`：长参数名拼成的本地错误默认单行，超出表单 → 在原错误行内按可用宽度折行。
8. `settingsui.go:7597`：宿主拒绝的长错误默认单行，越过卡片边 → 按当前表单宽度折行，保留原文与恢复出口。

复现后收敛：回调与稍后刷新属于同一个条件修复，不单独凑两项；补查两处错误呈现，分别以尺寸断言和截图复现。

行为红线：高度链、既有 Tab/Enter 模型、终端会话、设置写回、i18n 文案、命令接线不变；新增本地原因复用 RunParamInvalid(ParamsDefault)，不放宽后端校验，不改变保存/运行时机。声明编辑器与运行参数表单为两个组件。

Mutation：M1 去掉数字/布尔默认值校验，两个声明 pin 应红；M2 去掉选择默认值校验与占位符焦点出口，两条应红；M3 去掉默认值条件比较，known/unknown × later/callback 四条应红；M4 去掉两类错误文本折行，两个布局 pin 应红。每组 MD5 逐字节还原、touch 后重跑。

这轮更轻的原因：错误只在真正相关的参数记录盘内出现；默认值改变后过期红字及时撤下，恢复可读层级，不加新的面或浮层。

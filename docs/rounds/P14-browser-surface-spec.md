- `internal/shell`：后台扫描与有期限缓存，配置页使用快照，不等待文件扫描；当前已保存目标保持可见。
- 回归：模拟平台路径与文件、Edge 非默认配置、扫描后新增浏览器、切页不启动入场；深浅终端截图复核。
- 设置文件格式、未知字段与会话生命周期保持兼容；只读浏览器文件。
- 验证：中文 locale，针对性测试，统一 verify（vet/test/build 三平台）；最后检查 diff、提交 push。

# P13-gj · 浮层的顶边：影、描边、冠，三段里谁在干活（规格）

**意图一句话**：把 §6.154 对 E1 顶边做的「形状尺」搬到 **E2（浮层）** 上，量出浮层的
顶边是不是也是「分离 + 冠」两层——如果不是，谁在替它做分离。

**为什么现在做**：P13-gi 报告的「仍待」第 4 条自己点名的下一格：「`§6.139` / `§6.153`
那两把形状尺可以搬到**浮层（E2）**上——E2 的顶边是 `EdgeHighlight`（浅 0.92 / 深 0.20），
本轮只量了 E1」。证据在代码里：E2 的栈是四件东西（`internal/shell/notices.go:370`
`Border(1, InputStroke)`、`:398` / `:401` `InsetShadow(0, 1, 0, 0, EdgeHighlight)`、
`:400` `theme.ElevThrow`），而 §3 的表只给了 token 的 alpha，**没有任何一条 pin 说明这
四件东西在帧里各占几级**。§2 判据 3 说 E2 是「面 + 两层影 + 一条受光边」——本轮就是
把这句话读成像素。

**量法**（写死在测试的注释里）：
- 窗玻璃默认 47%，`ui.Tester` 的缓冲是预乘的 → `straightLuma` 先把框自身 alpha 除回去；
- 盒子边界用 **alpha 台阶**定位（`Float` 面叠在 47% 框上 = 196，纸面 = 127），不用亮度
  （浅色档盒沿只比纸面高 3 级，alpha 有 70 级）；
- 「地面」取**同一行同一列的、还没有这张浮层的那一帧**，于是「影有多重」是同一像素的两次读数。

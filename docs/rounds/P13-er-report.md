# P13-er 报告 · 浮层的满态：软边把最后一格留白吃掉了

表面 = **插件配置浮层**（`internal/settingsui/pluginsheet.go`）。规格
`docs/rounds/P13-er-spec.md`，合约新增 **§6.113**。

**这轮为什么让它更「轻」/更有空间感**：满态（滚到底）时，浮层原来根本没有下沿的空气——
它给自己的那 10.8px 留白，正好等于它自己那条软边的高度，软边于是把那格留白整个吃掉，
最后一张卡的边离软边上沿只剩 **1.2px**。补上一格之后（18.0 = 软边 10.8 + 一格 7.2），
最后一张卡第一次「结束」而不是「被切开」，而**软边的透明度一档没动**——层次还是那张面，
只是它下面终于有空气了。

## 量到的三件事

1. **软边与留白同数**。浮层的底边软边是 `Height(t.Space(3))`（10.8），下内边距也是
   `Space(3)`（10.8）。滚到底实测：带子最下 **11 行**空白，第 12 行就是最后一张卡的下边
   （`spreadAt` 17~31 级，那是卡自己的边，不是字）→ 净空 **1.2px**。
2. **同一套机制在设置体上是对的**。`Padding(edge, 0, t.Space(6), 0)`（`settingsui.go:1559`），
   `edge` = `Space(4)` = 14.4 软边，下留白 21.6 = **软边 + 一格 `Space(2)`**。所以规矩不是
   「一个好看的数」，是「软边 + 一格呼吸，各自代入自己的软边高」：设置体 14.4+7.2=21.6，
   浮层 10.8+7.2=**18.0（`Space(5)`）**。
3. **页头不能跟着挪**。停在开头时顶部空白是 11 行（§6.72 的 0.2px 余量），这一轮只在
   **下沿**加呼吸，顶部 `Space(1)` 与左右 `Space(4)` 一个字节没动——`rest` 帧改前改后
   **逐字节相同**（`cmp` 无输出）。

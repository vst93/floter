# P15 · 设置交互、终端拖动与 Edge 读取

本轮承接已有未提交修改，处理用户提出的三个问题。

| Before | After | Why |
| --- | --- | --- |
| 设置选中/悬浮背景圆角与叠层待核对，侧栏选中直接跳变 | 统一状态层的圆角；侧栏选中背景短距离平滑移动 | 保持状态清晰，页面内容立即切换，减少动态效果时即时完成 |
| 终端仅在文字上声明 DragWindow，顶部大部分区域穿透 | 明确的可拖动手柄，与终端第一行选区分开 | 拖窗口和选文本不争抢同一手势 |
| 浏览器目录读取失败被当成未安装 | 保留不可访问浏览器身份，给出原因与恢复入口，其他可读来源继续返回结果 | Edge 不会静默消失，其他浏览器可正常返回 |

本机只读检查：Microsoft Edge 应用与标准数据目录存在，读取目录返回 EPERM（Operation not permitted）。不读取或记录个人历史、书签内容，不绕过系统权限。

保持设置格式、未知键、已有用户修改。验证采用中文 locale；用注入的文件错误、合成浏览器配置与 UI 输入测试覆盖，无头截图记录圆角与动画关键帧。必要时记录无法验证的系统权限与原生拖动实机部分。

门槛：gofmt、go vet、适用包与专项测试、三平台构建。已有全量测试失败见 P14-glass-readability 报告，本轮不把既有失败算作新回归。

用户澄清：Edge 缺失于浏览器列表，本轮聚焦发现与访问反馈，不扩大到自动标签页聚合。追加：开关开启时采用稳定的蓝色底，与白色滑块形成清楚对比，覆盖设置、插件配置和终端抽屉。

## 八项与批次

1. 准备失败丢草稿 → 恢复全部本次输入（含脚本、参数、平台、声明）→ 真实失败后重新提交相同请求。
2. 权限取消丢草稿并报失败 → 安静恢复 → 审核拒绝后通知0条、仓库无新增、可重试。
3. 提交失败丢草稿 → 同一恢复出口 → 审核后移除声明触发提交错误，原输入可重试。
4. 等待时可再次连接 → 原提交入口忙态与宿主互斥 → 重复点击和直接调用均不增加工作。
5. 程序选择器错误无反馈 → 复用已有宿主警告 → 一次错误一次提示，原值保留。
6. 键盘取消选择后留在选择按钮 → 返回程序输入 → 取消后直接键入能编辑原路径。
7. 选择成功后无法直接修订路径 → 返回程序输入 → 新路径可立即继续编辑，过期表单不夺焦点。
8. 连接提交收起表单后键盘悬空 → 回到原添加入口 → 等待结束可用键盘重开，其他焦点不被抢。

每项先事件复现；每两项通过定向检查与vet后commit/push。旧V/B/S断言零改，新增Skip零。高度链、键盘快捷键模型、会话、保存事务、i18n、命令接线零改；不碰生成工具覆盖和重装事务。

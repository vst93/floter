# P13-ge 规格 — 禁用的开关仍要说得出它现在是哪一档

## 意图

「不可用」这一族已经量过三次：淡了几次（P13-u）、槽该不该叠材质（P13-t）、禁用面熄不熄灯
（P13-s）。三次都在问**它被淡了几次**，没有一条问**淡完之后那句状态还在不在**。一枚开着的
开关被禁用后，如果与一枚关着的开关禁用后长得一样，它就在说反话：用户读到的是「这个功能
关着，而且点不动」，实际状态是「开着，只是现在改不了」。本轮只量这一句，不改交互、不改语义。

为什么现在做：`docs/liquid-glass.md` §6 没有 `未开始` 行、用户实测无新条目、合约「下轮」
注脚全落、通用队列「状态反馈」格的**指针**那一半（P13-fi）与**材质**那一半（P13-s/t/u）
都已收口，剩下的半个格子是「禁用之后状态还读不读得出」——这是同一格里唯一没有被量尺碰过的
一格，也是这一族里唯一能靠**减法**（少一层淡、少一个错填）说清楚的事。

## 这一轮为什么让它更轻 / 更有空间感

禁用的槽是「退到 z 的下一层、但还在 z 上」：轨道离地面留一点台阶、旋钮对轨道留一点对比。
半道淡之后这两点各剩多少，此前全是散文。量出来才知道它们是「一层薄薄的槽」还是「糊进纸里
的一块」——**这就是「空间感」在状态反馈这一侧可被证伪的形式**。

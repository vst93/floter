## 这轮为什么让它更轻 / 更有空间感

层级是一套**允许关系**：一页 1426 高的内容只有 523 的窗口，键盘是唯一在动的那一层——
它必须带着身体走，而且**只往下走**。这轮把这条关系钉成 16 站 + 一次绕回的帧上不变量：
没有一站是死的（最少 552 px 真实变化），绕回是真的后退一整屏（−1026 > 523），
第二圈与第一圈同序。于是「空间感」不再是一句形容词：**往下走 = 身体跟着下去，
走到底 = 身体回到顶上**，这两个说法现在由同一张帧守着。

| 改动 px（浅） | 812 | 1948 | 1792 | 126890 | 177576 | 171148 | 151117 | 144321 |

| 站 | 9 | 10 | 11 | 12 | 13 | 14 | 15 | 16 |

第 17 步**绕回**：`1210 → 184`（一步 −1026），改动 139608 px；随后 5 站停在 184
（1634 / 1792 / 932 / **552** / 1276），再 `206.5 / 324.5 / 457 / 572 / 664 / 749 / 872 /
1043 / 1125`——**第二圈就是第一圈**。

反向（从 1210 起）：`1210 ×4（328 / 828 / 1732 / 1256）→ 1167 → 1059 → 950 → 827.5 →
709.5 → 641.5 → 589.5 → 529.5 → 410 → 286 → 184`，再绕回 1210。

**防误判的事实**：`Y` 落在 x.5 上但**不糊**。同一份内容在 `Y=0` 的线行是 180/182
（强度 30/6），在 `Y=26.5` 是 154/156（强度 30/6）：整份内容按 **26 行整行搬**，
没有「两条半强度的行」。「把滚动偏移取整」因此不是待办——这条差点被当成一个假选题。

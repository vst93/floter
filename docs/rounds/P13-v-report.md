# P13-v 报告：满态的下折边——只露一半的行**退后**，不是被切

**设计读取**：桌面启动器（结果列表的满态折边），面向键盘优先的高级用户，用克制 /
近黑的编辑气质，倾向 Raycast 家族 + 轻便液态玻璃（自绘等价物）。
拨盘：冒险度 4 / 动效强度 3 / 信息密度 6（功能页起点，不往上抬——这一轮只改「墨」）。

**这一轮为什么让它更有空间感**：折边原来是**硬切**。同一帧里 24px 高的行文字被切到
15px，墨在视口下沿一刀断掉（实测 `Walk 09` 文字盒 `{54,428,63,15}`，整行可见时
`{54,409,60,24}`）。一个被水平切开的字母不表达「下面还有」，它表达「界面坏了」——
所有东西还是挤在同一个 z 平面上，只是其中一层被刀切了。改成「按露出比例退后」之后，
折边自己就是深度刻度：露出 23/40 的行画 57.5% 的墨（最深 27 → **123**，面 253），
露出 15/40 的更淡，整行可见的一行**一点都没变**（27 → 27）。越过折边的东西在
**后面**，不在**下面**。

## 落地（`internal/launcher/launcher.go`）

1. **新纯函数 `foldAlpha(viewport, box)`**：整行在视口内 → 1；被折边切 → `可见/行高`；
   滚出视口 → 0；首帧没有盒子 → 1（画面不会先空一帧）。两个盒子都用**上一帧**的
   （`a.listRect` / `a.rowRects[i]`，与编号家族同一套前提），所以互相自洽。
2. **`rowBody` 下发一次墨**：行墨 = min(静息档, 折边比例)——历史行的 `0.92` 与折边取
   更暗的那一个；只在 `< 1` 时调 `row.Opacity`，整行可见的行拿到的是和以前逐像素相同的值。
3. **页脚不参加折边**：动作栏是钉在面板底部的 footer，只是被记成列表最后一行好让
   高度链把它算进去；它的盒子永远在视口之外，按折边算就是 0 —— 实测会把整条动作栏
   抹掉（选中块 tint 全丢、块从 `x=-1` 起算）。这条是变异 M3 抓出来的，写进代码注释。

**不做**：不给折边加渐变遮罩（那是拿背景色回放冒充玻璃，§0 禁）、不补滚动条
（用户定过「列表不要滚动条」）、不改行高与视口高度（高度链是红线）、
不动 `output.go` 的捕获输出列表（同族，另起一轮）。

### 偷了什么（逐条落到具体数值）

- **`craft-loop.md` §二 工艺密度菜单第 9 项「自定义滚动条」→ 反面取用**。菜单给的是
  「细窄 + 品牌色 thumb」，本仓用户明确要过「列表不要滚动条」，所以取它的**功能位**
  （告诉用户还剩多少）改用「折边退后」实现：`alpha = 可见高度 / 行高`，露出 23/40 →
  0.575。这是第 9 项在「无滚动条」约束下的等价物，不是把菜单项丢掉。
- **第 4 项「签名交互（一个足矣）」**：折边退后是列表唯一的「还有更多」信号，
  不再叠第二个（不加遮罩、不加滚动条、不加计数徽章）。
- **第 12 项「材质细节（内边框高光 / glass 折射边）」→ 只取「不改材质」那一半**：
  折边不改材质、不叠 glass、不加受光边，只改墨的 alpha。理由写进代码注释：
  真透明度只给窗口层（`docs/liquid-glass.md` §1），组件层自造透明必糊。
- **第 5 项「多层染色阴影」故意不取**：折边不是影，把影加在滚动中的行上会随滚动闪。

### preflight 逐条结论

- **A（反 AI 套路）**：过。自绘仓没有渐变/紫蓝/斜体/emoji；本轮唯一新增的视觉量是一个
  alpha 值，且**没有**新增任何「类玻璃边」「渐变白边」——正是用户点名要退掉的那一类。
- **A2（进攻三步）**：**部分过，如实记录**。DNA 注入：供体不是 58 站库（本仓是 Go 自绘，
  没有 CSS），用 `docs/liquid-glass.md` 当唯一设计锚，偷的是它的 §2 elevation 语义
  （「越过折边 = 退后」）。工艺密度只落到 3 项，**没凑满 5 项**——本仓单表面一轮、
  禁氛围层、禁装饰性动效，凑数就是加噪点；这一条按「不能过要写为什么」记在这里。
  两轮制：第一轮落地 → 四视角评审（艺术总监：最平庸的是折边那条硬切线；工程师：
  页脚被折边抹掉 = 必修，M3 已修；甲方：三秒记住的是「列表在往下退」；读者：
  淡到 123 的行仍可读）→ 第二轮只修页脚那一处。
- **B（设计读取一致性）**：过。没有新增 z 层（E0/E1/E2 三档不动），单页单主题，
  记忆点一句话：「列表的底边不是被切，是退后」。
- **C（动效抽查）**：**有一项如实记为风险**——折边的 alpha 目标值挂在行既有的
  `rowTransition`（120ms）上，所以滚动时它是一条 120ms 的淡出，而不是瞬时状态。
  高频键盘滚动本该无动画（C 第 1 条）；本轮没有为此改 `rowTransition`（那会动到
  打字时的入场淡入），写进「仍待」。
- **D2（中文页）**：过。本轮零文案改动、零 i18n 改动。

## 仍待（P13-v）

1. **捕获输出页（`output.go` `outputBody`）的列表没有折边退后**：同一个 40u 行盒、
   同一个「没有滚动条」的约定，它的折边现在仍是硬切。同族，下一轮可一轮收掉
   （它有自己的 `OutputList` 视口，`a.listRect` 那套不能直接复用）。
2. **折边的 alpha 走行既有 120ms 过渡**（preflight C 第 1 条）：要不要给折边单独一条
   无动效通道，需拍板（会动 `rowTransition`，那也管打字入场）。
3. **淡到 123 的行在深色档的可读性没有像素 pin**：本轮 pin 只跑默认（浅色）外观，
   深色档只有出图。补一条双外观 pin 是下一轮的小活。

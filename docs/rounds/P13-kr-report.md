## 为什么更轻、偷了什么

提示占用原表单的空间时，活动控件仍在正文可见区域，用户能直接继续编辑或恢复操作；保持原有面差与焦点墨，不增加外框、玻璃层或常驻提示。

- 从craft-loop.md菜单第3项取品牌focus环：保留深#8FB7FF/浅#064AA6与3px原环，沿用19px包络避开16px滚动淡边。
- 第4项取一次滚动显现：提示内容变化只触发一次，额外动画0ms；普通输入值和滚轮偏移不进入触发量。
- 第12项取材质克制：字段原28px槽、原胶囊与图标面保持，新增受光线/阴影/透明层均0。没有为凑五项装饰改变产品方向。
- Linear供体的#0f1011近黑面、0.05–0.08发丝线、单一交互accent映射到本仓#0E0E10、ControlEdge深0.07/浅0.06与原蓝色，未复制字体或紫色品牌。

# P13-ij · 复制与导出能力变化后的键盘归处

意图：当前操作失去宿主能力后，键盘回到它自己的内容；能力恢复不打断当前选择，不误走到另一条链接。开盘 07cba797，最新 P13-ii 仍待优先于任务书旧 P13-hw。实际 ui.Tester 点击、Tab、Enter 与宿主 Actions 刷新已复现四个工具动作丢焦点、两个链接禁用后不能键盘选取，以及第二条链接恢复后 Tab+Enter 复制第一条。

读取为：现有设置的工具表单和关于页，面向键盘用户，轻便液态玻璃、克制的即时状态反馈。视觉冒险 3/10（遵循现物）、动效 2/10（高频操作即时）、密度 7/10（保留现有信息量）。功能契约：三秒内看出当前内容与可用动作，能力变动后可继续编辑或选取内容。

- craft-loop 工艺密度菜单 **#6 编辑细节**：数字的显示/派发共用步长网格；输入 3.7、Step=1 落成 4，存量 30、Step=20 的滑块落在 40。不是增添装饰数值。

- Apple 供体取 48% 弱化、8px 标准圆角、交互蓝只给可操作态，映射到既有 0.5、RadiusSM=8、锁定中性墨。拒绝照搬网页模糊、超大字号与展示结构。

按用户限定的现有功能打磨与 craft-loop 的优先级，没有为凑五项菜单增加噪点/动效。为什么更轻、更有空间感：禁用文字退回既定弱层，槽面层级得以保留；同一个输入只显示一份当前答案，过期草稿退场。

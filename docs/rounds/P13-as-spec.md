# P13-as 规格：满态的下沿不是一刀切——设置页底边补上顶边那道软边

## 意图

**设置页滚起来之后，下沿是一刀切：字的最后一行在窗口最后一行像素上被水平切断，
墨一点没退；而它的上沿早有一道 `glass.ScrollEdge` 软边。同一块面板，一头是软边、
一头是刀口。** 为什么现在做：`docs/liquid-glass.md` §6 无 `未开始` 行，按纪律走通用
队列「空态/满态」的**满态**那一半（P13-ap 做的是空态，P13-ar「仍待 4①」点名的就是它）。
启动器的满态早就有折边（§6.1 表 1-10：视口下沿落在行中间时，墨 = 可见高度 / 行高），
设置页这块自由滚动的面板是同一族里唯一没有处理下沿的表面。

一句话：**这轮让满态的下沿也「退后」，不是让内容在窗口边缘断气**——满态不再是一张被
裁掉的纸，而是一页在底边继续往下读的内容（空间感来自「它还在、只是暗了」，不是「它没了」）。

## 证据（改动前实测，`internal/settingsui`，720×580，General 页）

探针：把 `a.Body.Y` 逐档设在 `[0, MaxY]` 上（21 档），量**窗口最后一行**在内容列
（x∈[240, 696)）的墨展开度 `max(luma) − min(luma)`：

| Body.Y | 窗口最后一行（y=579）的墨 | 读数 |
|---|---|---|
| 0（静止） | 无内容 | 0 |
| 329.73（30%） | `lo=27 hi=246` | **219**（满对比的字被切断在窗口边缘，浅色档） |
| 439.64 | `lo=130 hi=229` | 87 |
| 659.46 | `lo=229 hi=255` | 167 |
| 879.28 | `lo=128 hi=229` | 202 |

深色档同样的档位：`15/233` = 222、`39/132` = 81、`24/40`、`39/229` = 190。

也就是：**只要滚到某一档，字就有一整行落在 y=579（窗口最后一行像素）上，墨是满的。**
上沿的处理（`settingsui.go:1496-1505`）是把 4u 的高度**预留**成 padding
（`Padding(edge, 0, t.Space(6), 0)`），再在预留区上盖一道 `glass.ScrollEdge` 的软边：
静止时软边下面什么都没有（看不见），滚起来时内容淡进背景。下沿什么都没有。

## 逐条落地项（动手前核对过的真实位置）

1. `internal/settingsui/settingsui.go:1496-1505`（`body` 的滚动边）
   - 现状：只有 `Absolute().Top(0)` 那一道 `glass.ScrollEdge{Background: t.Background}`。
   - 改为：补一道 `Absolute().Bottom(0)` 的 `glass.ScrollEdge{Bottom: true, Background: t.Background}`，
     高度、`PassThrough()`、`Left/Right` 与顶边**逐字段相同**。
   - 不新增 padding：`Padding(edge, 0, t.Space(6), 0)` 的底部已是 6u ≥ 边高 4u，
     滚到底时软边落在空白上（下面没有内容可淡），所以**盒子零改动**。
2. `internal/settingsui/bottomedge_test.go`（新）
   - ① 满态下沿是一条**渐变**而不是刀口：在各种滚动位置上，窗口最后一行的墨展开度
     **≤ 边上方那几行最大值 的 0.45**（改前实测 219 / 219 ≈ 1.00，红；改后见报告）。
   - ② 自门控：滚到底（`Y = MaxY`）时，最后 4u 的像素**只有面板自己的颜色**
     （逐像素偏差 ≤ 2 级）——软边不许在没有内容滚过时留下一道灰带。
   - ③ 边上方的墨必须真的存在（≥100 级），否则 ① 会在一个空页面上假绿。
   - 深浅两套各跑一遍。
3. `internal/settingsui/bottomedge_dump_test.go`（新，opt-in 出图）
   - 满态 × 深浅两套出 PNG，`FLOTER_P13AS_TAG=before` 拍改前那一帧。
4. `docs/liquid-glass.md` §6.16（新）+ `.pending-bugs.md` 顶部本轮段。

## 行为契约零改动红线

高度链、键盘模型、会话管理、设置写回、i18n 文案、命令接线**一律不动**。特别地：

- `a.Body.Y` / `MaxY` / `TrackScroll` 逐字节不动（`wheel_test.go` 的 B 类 pin 零改动必须绿）；
- 滚动区的 padding（`edge, 0, 6u, 0`）不动 → 内容盒、`MaxY` 与改前相同；
- 带宽 `Absolute()` + `PassThrough()` → 不参与布局、不吃指针（`uninstall.go:36` 那族的老办法）。

# P13-iy：快捷键表单的编辑与退出归属

意图：修复现有快捷键设置中命令输入、草稿与录制器的边界状态，让原行继续承载原动作及键盘出口。开盘 a74fcfb5，工作区干净，沿 P13-ix 仍待检查；不重复暂停注册与草稿取消修复。

设计读取：功能型设置页，日常桌面用户，轻便液态玻璃，视觉变化 2/10、动效 1/10、密度 6/10。三秒内可识别当前绑定、正在编辑的命令与拒绝原因；必须能保存、取消、重试。只修状态与已有表面。

## 现场位置与候选验收

- custom.go:552–561：命令 Enter 通过动作菜单的 sentinel 分支；字面 `command` 应仍是可保存的命令。
- custom.go:345–378：草稿编辑器随模式出现/离开，核对文本、Bind 与取消后焦点归属。
- custom.go:219–239：录制后 key 改名，核对原行退役与目标 recorder 焦点竞争。
- custom.go:570–586：已存在草稿时，另一保存行转 command 会覆盖共享 customKey/customCommand；先真实事件复现，涉及多草稿/阻止转换/确认覆盖的选择则记需拍板。

后续独立缺陷以实际红灯补齐清单，不把候选或同一个断言按深浅主题拆项。

第二批已实证：custom.go:220–237 换键错误丢弃同一行的待提交命令，改为迁移草稿；settingsui.go:4323 长组合键文字不能收缩，720px 页越出键帽压邻控件，改为单行收缩省略。两项分别钉真实输入提交与文本/删除按钮边界。

第三批现场图：custom.go 的 customShortcutRow / customDraftRow 与 rows.go:1675 的不可收缩控制列叠加；large 档保存行选择器压住删除，草稿命令选择器盖住录制键。只为快捷键行分配最小前列 30u、允许后列与命令框横向收缩；不改高度链/字号/正常键盘顺序。各自有相邻边界与真实点击 pin。

第四批：custom.go:434–442 把缺失 action/plugin 当命令，显示原 ID 并允许选择真实命令模式；custom.go:520 Bind 无条件清 customDuplicate，改成只清草稿归属。第五批候选：customShortcutRow 菜单回调失败仍排 customFocusDraft；用实际 Store 写失败复现，成功转换后才排焦点。

## 零改动红线

高度链、键盘模型、会话管理、设置写回时机、i18n、命令接线；3000ms/5000ms、180ms/Flush、终端待拍板项不改。既有 B 断言零改，V/S 如需改变明确台账。

## 验证计划

基线全量 verbose 正在运行；测试函数实测 3165。每批 1–2 个修复跑相关事件测试和包 vet 后 commit/push；全轮一次 gofmt、三平台 vet、普通与 verbose 全量、三平台 build，数字只记录实测。统一 LC_ALL=zh_CN.UTF-8、GOMAXPROCS=4，必要时 -p 1 控制包并发。

Mutation 至少两组：恢复命令 Enter 的 sentinel 路径，应令命令保留 pin 红；恢复焦点/状态旧出口，应令对应真实事件 pin 红。每次 MD5 保存→注入→实红→还原校验→touch→-count=1 复跑。

## 设计工艺依据

已读 qiaomu-design、偏好账本、craft-loop、preflight、chinese-typography 与 Apple DESIGN。沿用单蓝交互色、2px focus、8px 常规控件角；菜单 #3 让焦点返回真实控件（0ms），#4 保留单一录制者，#6 拒绝说明归属原行，#12 保留 1px 受光边且新增玻璃层/阴影 0。状态准确后无需额外永久说明，既有面之间保持空间层次。

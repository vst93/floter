## 为什么更轻、偷了什么

窗口变小后，当前活动边仍留在正文可见区域，用户不用凭记忆操作屏外控件；沿用原面差与焦点墨，不新增框、玻璃层或提示条，空间层级由原正文视口与活动出口保持。

- 从craft-loop.md菜单第3项（品牌focus环）取完整可见的焦点墨：原accent深#8FB7FF/浅#064AA6、原3px外扩环，复用19px包络避开16px页面淡边。
- 第4项（签名交互）：尺寸变化仅触发一次滚动显现，额外动画0ms；滚轮与输入值不作为触发量，稳定视口连续两帧不抢回位置。
- 第12项（材质细节）：原字段28px槽与原胶囊保持，静息32组PNG逐字节相同；新增受光线、阴影、组件透明度均0。菜单中的五种新装饰不适用于本轮，用户限定已有方向的bug打磨优先。
- Linear供体#0f1011近黑面、0.05–0.08发丝线和单一交互accent，映射到本仓既有#0E0E10、ControlEdge深0.07/浅0.06与蓝色；没有换字体或品牌色。

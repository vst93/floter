# P13-jz · 本地工具选择与内容回调的草稿归属

意图：原生选择器和内容操作返回时，只能影响发起操作时仍有效的草稿，用户的新输入、折叠和导航不能被旧结果倒退。开盘HEAD为8a6cf2df，P13-jx/jy已完成任务书上一格；接续最新报告的同表单回调线索。

读取为已有原生集成设置表单，面向连接本地工具的用户；视觉冒险3（可预期）、动效2（即时）、密度7（保留信息）。轻便液态玻璃方向已定，不做四方向预览。功能契约：能看清当前草稿，选择/复制/导出只作用于自己的操作，错误后能继续输入。

## 动手前位置与八项计划

1. settingsui.go:5836/5950/5971：选择器只校验form/open，局部字段整份写回 → 同表单模式/字段已改时拒绝旧返回且不覆盖新草稿。
2. settingsui.go:5840：选择错误只有通知 → 保留原警告并恢复原程序输入焦点；退出或新焦点不被夺取。
3. settingsui.go:6199/6203/5971：复制回调只校验form/open → 命令、执行计划、脚本变更后旧成功不得确认，也不得覆盖新输入。
4. settingsui.go:6137/5950：导出回调后旧局部变量仍写回 → 导出的是点击时快照，回调内的新草稿原样保留。
5. settingsui.go:5751/5837：折叠再打开form指针不变 → 选择结果及错误不能跨过这次退出。
6. settingsui.go:5751/6203：复制回调跨折叠重开仍确认 → 新打开的相同内容不冒认旧复制成功。
7. settingsui.go:1628/5837：离开集成页再返回未撤销旧选择 → 页面离开使旧回调退役，重选当前页不退役。
8. settingsui.go:1633/6203：导航已清确认，晚回的复制又点亮它 → 旧复制不跨页复活，返回后新复制正常。

每两项形成一批，先事件复现，再实现、定向测试与vet、commit/push。若线索不成立如实调整，不把代码猜测计作修复。前两项属于选择器组件，后续覆盖内容操作与导航生命周期。

已读qiaomu-design、偏好账本、craft-loop、preflight、chinese-typography，并按需读Carbon工作流与Apple供体。采用Apple的单一交互蓝、8px矩形控件半径、平面与浮层阴影职责，映射本仓现有token，不复制品牌数值。craft-loop菜单#3：错误返焦点等待0ms、1个有效输入；#4：结果只属于1次有效操作；#12：保留1px受光边，新增材质/阴影0层。用户修已有功能优先于凑满五项装饰。

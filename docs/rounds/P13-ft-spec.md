# P13-ft 规格：`cardRow` 的三重极限——窄窗 × 长标签 × 长值

## 0. 意图（一句话）

设置页里有一类标签**不是本仓写的**：扩展自报的包名、命令名、别名，长度由发布者决定。
前两轮把「控制槽不吃标签列」（§6.132）和「结果格最长那句答案」（§6.129）各钉了一次，两次
用的都是本仓自己的文案。本轮把**用户数据**拉到极限，量 `cardRow` 在「三者同时成立」时
还剩多少余量，以及退化方式是哪一种。

为什么现在做：`docs/rounds/P13-fs-report.md` §9 的第 1 条就是它；通用队列里
「间距节奏 / 状态反馈 / 空态满态 / 文案密度」四类都已收口，只剩「边界情况」与「像素细节」。

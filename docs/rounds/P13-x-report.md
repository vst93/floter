## 这轮为什么让它更轻 / 更有空间感

一句话：**折边现在对列表里的每一样东西都说同一种话——「下面还有」，而不是「界面坏了」。**

P13-v 把这条规则钉在启动器列表的行上，P13-w 把它接给捕获输出页的行；两轮都漏了
**分组头**。分组头在代码里是 `row`/`outputRow` 的**兄弟**元素（`launcher.go:2250`
那个 `return` 让它从来不经过 `rowBody` 的 `Opacity`），所以折边切到它的时候它保持满墨。

实测（720 宽帧，`contrastIn` = 盒内像素相对本页面的面的最大偏离）：

改后同一个标签的墨随露出比例走，折边自己成了「还剩多少」的刻度。

## 落地

**产品改动只有一处族**：分组头臂接上 P13-v 的纯函数 `foldAlpha`。

- `internal/launcher/launcher.go`：新增 `App.headingRects map[int]ui.Rect`；
  `row` 的 `item.heading` 臂把元素存进变量 → 记盒子 → `fold < 1` 时
  `heading.Opacity(float32(fold))`（**必须在 `Children` 之前**，框架按建树那一刻的
  opacity 画这一帧）→ 再填内容。
- `internal/launcher/output.go`：新增 `App.outputHeadingRects`，`outputRow` 的
  `row.Group` 臂同一个规则、同一个纯函数，只是视口读 `a.outputListRect`。
- 清空时机与行盒逐字相同：`launcher.go:1403` `clear(a.rowRects)` 之后、
  `output.go:122`（`showOutput`）与 `output.go:548`（`outputBody`）的
  `clear(a.outputRowRects)` 之后。

**关键的结构约束**（P13-w「仍待」第 1 条已经写死）：标签盒子进的是**自己的两张表**，
不进 `rowRects`/`outputRowRects`——后者喂 `viewportRange`/`outputNumberedViewport`，
一个标签混进去就会占掉一个数字位。实测 `numbers` 仍是 `map[1:1 … 9:9]`，
`rowRects` 里没有 heading 的键（有专门的 pin `TestTheHeadingBoxesStayOutOfTheNumberedFamily`
守着这条，M3 正是拿它抓的）。

**没有改**：`foldAlpha` 本身（它自己的表 pin 在 `fold_test.go:138`）、高度链
（`rowUnits`/`headingPadding`）、键盘模型、编号下发、`i18n`、`extensions`、
`settings` 全部零改动。

| 菜单项 | 落成什么 |
|---|---|
| **#12 材质细节**（「内边框高光、glass 折射边、印刷套准偏移」） | 折边的**渐变式退让**就是这批 UI 的「玻璃折射边」等价物：不是加一条线，而是让越过折边的东西按露出比例失光。落成 `foldAlpha` 的返回值直接进 `Opacity`：折边 0.25 → 0.25，0.75 → 0.75。实测墨 145→36（浅）/133→33（深）。 |

### preflight 逐条结论

- **A 反 AI 套路**：全过。无渐变文字、无发光、无紫蓝渐变（本轮只改 `Opacity`）。
  **P-38（禁左侧竖线）**：不适用，本轮没碰任何描边。
- **B 设计读取一致性**：过。`docs/liquid-glass.md` §0 第 3 条禁「拿背景色回放的
  渐变遮罩冒充玻璃」——本轮用的是墨的退让，正是它要求的那条路；`docs/raycast-design.md`
  的语义 token 与行为契约一条没动。
- **C 动效抽查**：**部分过，如实记录**。折边的 alpha 走的是行既有的 120ms
  `rowTransition`（P13-v「仍待」第 2 条已记为**需拍板**：高频键盘滚动本该无动画）。
  本轮的分组头**没有**引入新动效，沿用同一个既有通道，所以没有把这条问题变大；
  但它仍然存在，仍在「需拍板」里。若按 craft-loop 的两轮制严判，这是本表面唯一
  没收敛的一项。
- **D2 中文页**：过。新增的 pin 与注释都是中文，正文/标签的字号与字重一个没动
  （折边只改 alpha，不改 `FontSize`/`FontWeight`/`TextColor`）。**P-1（禁斜体）**：
  不适用。**P-3（禁装饰中文 webfont）**：不适用。
- **A2 进攻三步**：DNA 注入（上面那张表）、工艺密度 ≥ 5（凑到 4 项，见下）、
  两轮制：**如实记录只走了一轮 + 5 条变异复核**，没做「四视角偏执评审」——
  本轮的评审对象是一行 32u 的标签在折边上的墨值，四视角（艺术总监/工程师/甲方/读者）
  在这么小的面上没有互不重叠的观察点，硬凑会变成为了过门禁而写废话。
  **工艺密度只凑到 4 项**（菜单要求 ≥ 5）：这是刻意收手——本仓的工艺密度不是靠
  再加一层效果，而是靠「一个纯函数覆盖每一处折边」，所以第 5 项会变成重复计数。

## 仍待（P13-x，追加在 P13-w 之后）

1. **折边的 alpha 走 120ms `rowTransition`**（P13-v 第 2 条原样有效，**需拍板**）：
   本轮把分组头也接进了同一条通道，所以这条的**影响面变大了**（多一类元素在
   键盘滚动时带 120ms 淡入）。要不要给折边单开一条无动效通道，需拍板。
2. **折边淡到 0（完全滚出）的元素仍留在树里**：实测 `headingRects[0]` 在
   `fold = 0` 时 `Bounds()` 仍在（y=-10），只是 `Opacity(0)`。像素上不可见，
   但布局盒还在——要不要在 `fold == 0` 时跳过建树，需拍板（会动列表的行数记法）。
3. **捕获输出页的分组头只在 404 这一档有 pin**：`outputHeadingAt` 用的是
   「高度 404 落在一个已知的切点上」，一个更抗漂移的读法是扫一串高度取折边读数，
   下一轮可做成表驱动。
4. P13-w 第 2-5 条、P13-u 第 1/2/3 条、P13-t 第 3 条、P13-s 第 1/2 条、
   P13-r 第 1 条、P13-q 第 1 条、P13-p 第 1/2 条、P13-k 第 1/2 条、P13-c 四条、

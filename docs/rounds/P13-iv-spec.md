# P13-iv：默认快捷键恢复与拒绝后的键盘出口

起点 `0726b2c4`，真实最新轮 P13-iu；P13-hw 提示的表单条件刷新已由后续轮完成。基线中文 locale 实测 **5129 PASS / 0 FAIL / 3134 测试函数**（实际源码计数，纠正上一轮报告 3132）。

意图：恢复默认或重新录制遇到 OS 拒绝时，保住已确认的键与可重试入口。证据：`shell/shell.go:2217` 先写默认后注册，`:1482` 同键提前返回不清旧错误，`:1498` 磁盘失败未清此前 OS 拒绝；`settingsui.go:4138` 恢复只观察文件错误，`:4131` 拒绝提示插入改变其后组的身份。

设计读取：原生快捷键设置面，桌面用户，既有轻便液态玻璃；拨盘 3/2/6。三秒内知道操作是否成功、现有键是什么，键盘可直接重试。为什么更轻、更有空间感：只在既有警告面显示当前失败，解决警告退场后残留及焦点漂移，不增加面层或常驻说明。

## 逐项计划（先事件复现，成立才计入）

1. shell 恢复默认：系统拒绝仍写默认值 → 注册成功后才确认写入，拒绝保原键与原设置。
2. 设置恢复按钮：系统拒绝没有页面反馈 → 读取已有 ShortcutRefused 回调，复用拒绝行与顶部提示。
3. 恢复默认成功：旧拒绝行仍在 → 本次成功清理该操作已解决的拒绝状态。
4. shell 录制：上次 OS 拒绝混进本次磁盘失败 → 开始新尝试清理旧操作错误，保留磁盘提示。
5. shell 同键恢复：重新选择仍在工作的原键残留旧拒绝 → no-op 确认后清理已结束的错误，不再注册/写入。
6. 内置录制组件：全页拒绝提示出现后失去录制入口焦点 → 稳定组身份，Enter 可重试原动作。
7. 恢复按钮组件：系统拒绝提示出现后失去恢复入口焦点 → 稳定身份，键盘可再次恢复。
8. 恢复按钮组件：成功后提示消失时失去焦点 → 保持原入口，下一次 Enter 仍操作当前按钮。

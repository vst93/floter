- craft-loop.md工艺菜单第3项品牌focus环：保留原环外3px，将其与16px淡边一起按19px包络显现；新落地的是健康/结果变化触发，不冒称本轮新画焦点环。

- Raycast DESIGN供体保留三项DNA：近黑底、语义强调、细边分层；数值仍由本仓token决定，不把网页#07080a或字体强加给自绘界面。工艺密度没有凑满5项，按craft-loop优先级与用户禁止装饰扩张约束，仅用三项与此缺口相关的机制。

四视角复核：艺术视角发现活动环被淡边/裁切吃掉；工程视角发现内容刷新无焦点事件；任务视角发现键盘能操作但看不到按钮；读者视角发现报告长文抢走当前输入。前后图与事件分别验证修正。没有新增页面或预览流程。

# P13-dz 报告：会话行的 56u 地板 —— 先量，处方被证伪

## 1. 意图与选题

选题 = `docs/liquid-glass.md` §6.86 的 **73-6**，那张表里最后一条 `未开始` 的**产品**行
（其余是取景债）：「会话行 49 对参考的 56 地板，少 7px，补 `min-height = Space(14)`」。
它同时是 `P13-dd-report.md`「仍待」第 1 条。

**为什么现在做**：新总目标把选题赶回「细节打磨」，而这一格是合约里唯一还开着的**产品**
行，且它属于「空间感」——一行的高度由内容说了算时，行距跟着数据走。

**结论先说**：处方**落不了地**。注入之后像素**一个都不动**。所以本轮交付的是
**证伪 + 主人定位**，产品零改动。

## 3. 注入与结果（这是本轮的实验）

注入（**已还原**，`git status` 干净）：`rowFace` 加 `Floor float32`；`cardRow` 里
`if face.Floor > floor { floor = face.Floor }`；会话行传 `rowFace{Floor: t.Space(14)}`。

- 编译过、`gofmt -l` 空；
- `TestTheSessionRowsHeightAgainstTheReferencesFloor` **仍然绿**，它量到的盒子仍是
  `160..208` = **49**。

**绿就是结论**：这一行的盒**不由行元素拥有**。`cardRow` 的 `MinHeight` 挂在
`ui.Row(...)` 上，外层（卡片的盒 / 页面的列）给了定高，行被 stretch 进去，那 1.4px 被吞了。
行级地板在本仓**没有落地的能力**，除非先改卡片几何。

**台账**：V 0 / B 0 / S 0（产品 0 行；`sessionrowbox_test.go` 只改注释）。

## 6. 偷了什么（`qiaomu-design`，走「已有方向，只要打磨」那条路径）

本轮读：`references/user-preferences.md`（头部规则与账本格式）→ `references/craft-loop.md`
（工艺密度菜单 + 参考 DNA 注入）。**没读** `preflight.md` 全文（预算），A/B/C/D2 按合约
既有结论对照，见 §7。

| 从菜单取的 | 落成哪个具体数值 |
|---|---|
| **第 6 项「编辑细节」**（hairline / 大写字距标签那一类「每页有意为之的细节数量」） | 把「49 对 56」从一句散文拆成**三项可复核的账**：行盒 49 / 标题内边距 8 / 参考地板 50.4，并把**谁拥有这个盒**单列成 73-6c 一行 |
| **第 8 项「流体字号」**（尺寸随刻度呼吸） | 处方的**单位**是对的（`Space(14)`，不是硬写 56px），错的是**挂载点**：同一个数在 `u = 0.9` 下是 50.4、在 `u = 1.0` 下是 56——所以「参考的 56」在本仓从来不是像素，是 14 个单位。这条写进合约，免得下一轮把它当像素抄 |
| **第 12 项「材质细节」** | 只取了「材料有主人」这一半：一个面/一个盒的数值必须由**拥有它的那一层**给，行元素给不了卡片盒的高度——与 §2「elevation 由面差 + 影 + 受光边表达，不由画框表达」是同一条纪律的几何版 |

**没凑满 5 项，照实说**：第 1/2/3/4/7/9/10/11 项是 web 产物的动作（氛围层、`::selection`、
focus 环、滚动条、SVG 资产、彩蛋），本仓是 Go 自绘、没有 CSS，硬套就是「假装有」——
正是 `liquid-glass.md` §0 禁令 1 点名的行为。

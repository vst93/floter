# P15 · 设置交互、终端拖动与 Edge 读取报告

进行中：本机 Edge 标准目录存在但读取返回 EPERM；现有浏览器发现路径会吞掉该错误。终端顶部只有标题文字声明 DragWindow，其余条带穿透。

实现和验证结果随工作增量更新。

已实现：分段选项内外圆角同心；设置行的悬浮/按下/选中形状统一，包含分组中间行；侧栏采用 180ms 移动背景，连续点击可反向，键盘和减少动态效果时即时完成。终端网格上方预留 10 DIP 拖动区，标题穿透，选择期间隐藏工具栏，Shift 可从按钮下面开始选择。首次观察器方案发现窗口外释放收不到事件，已改为读取框架捕获状态，释放与取消测试通过。

用户澄清 Edge 是「列表中没有」。已保留目录读取错误对应的浏览器身份，配置显示访问状态与完整恢复说明，重新打开配置异步扫描，显式目标不再回落到其他浏览器。模拟 EPERM/EACCES/权限恢复和多来源结果隔离已通过；实际系统权限仍需由系统授权。暂不扩展自动标签页聚合，避免把发现问题扩大到 Apple Events 授权行为。

追加用户反馈：开启开关的底色过白。共用开关独立使用饱和蓝色底，避免低透明度文字对比补偿把强调色提亮成近白色；设置页、插件配置、终端抽屉与加载状态一致。验证进行中。

回归验证发现并修复：终端工具栏加入顶部留白后按钮超出原高度 3 DIP，现总带宽含独立拖动条，抽屉不再重叠。开关初版局部 SetTheme 会重置整个窗口背景，影响实际不透明度；改为只覆盖开关底色，新增「开关不得改变窗口 alpha」像素测试，复验原透明度与 toast 边缘测试。

首次全量记录 2040 通过 / 109 失败。新增 8 项中，4 项终端几何/采样已修复或更新采样范围（剔除新拖动手柄）、1 项过渡源码约束已修复、1 项扩展进程 500ms 超时独立复测通过、2 项开关覆盖窗口透明度已修复。终端全包复测 120 通过 / 18 失败，剩余全在历史失败集合。专项测试还发现旧 hover 像素测量不符，使用修改前 overlay 核对，不直接放宽断言。

## 最终验收

| Before | After | Why |
| --- | --- | --- |
| 设置中间行悬浮为直角，分段选项内外弧度不匹配 | 每行统一圆角，分段内圆角减去内边距与边线 | 状态形状一致；选中行前导色条避开角部 |
| 侧栏选中瞬间跳转 | 180ms 位置过渡，可中途反向；页面内容立即切换 | 键盘与减少动态效果不等待，悬浮背景在选中时立即清除 |
| 终端只有标题文字可拖动，抢占首行文字 | 顶部 10 DIP 独立拖动条，标题穿透，选择时隐藏工具栏 | 首行可以开始选区，Shift 可从按钮下方开始选区，抽屉保持不重叠 |
| 低不透明度下开启开关与白色滑块接近 | 稳定蓝色开启底，关闭灰色，禁用保留状态色 | 文字强调色与控件填充解耦，白色滑块对比度超过 4:1 |
| Edge 目录访问错误导致浏览器选项消失 | 保留 Edge，显示访问状态与完整说明，重开配置重新扫描 | 权限失败不会伪装成未安装，指定 Edge 不会转搜 Chrome |

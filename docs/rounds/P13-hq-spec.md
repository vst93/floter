# P13-hq 规格：配置刷新后编辑与校验仍归当前字段

意图：插件重新分组不打断输入，集成配置的旧错误不遮住当前有效值。当前 HEAD ef5e7b13；用户临时主线优先，至少八项、跨插件配置浮层与集成配置表单，四批各两项提交推送。

设计读取：功能型配置表单，轻便液态玻璃；视觉冒险 2（克制）、动效 2（即时）、密度 7（原有紧凑布局）。功能契约：看清字段与当前值、继续输入、正确反馈合法性。为什么更轻：刷新不熄掉当前焦点边，过期红色提示退出，不额外增加材质层。

## 逐条落地项（开盘行号）

1. pluginsheet.go:239 分组按序号 key；前置分组让文本未提交草稿消失 → 让分组身份跟随存活字段。
2. pluginsheet.go:328/624 数字字段父分组变化时 `1e` 丢失 → 聚焦字段移动时保留其原分组身份与编辑器。
3. config.go:203 外部纠正文本后旧长度错误留下 → 接纳未编辑宿主值时退役旧校验。
4. config.go:203 外部纠正数字后旧范围错误留下 → 同一刷新路径覆盖数字，仍保留真实本地编辑。
5. config.go:701 未修改文字按 Enter 验证后，放宽长度限制不清错误 → 对已显示的错误重新按当前 schema 验证。
6. config.go:701 未修改数字按 Enter 后放宽范围不清错误 → 同上，只更新校验，不写值。
7. config.go:295 仅遍历 live 退役移除字段错误；无 live 的文本错误会复活 → 按可见字段独立清理错误。
8. config.go:295 数字同一路径旧错误复活 → 独立事件覆盖移除/重加与新值。

1–6 已有原实现真实事件红证据；7–8 在所属批次先复现，未红不计修复。

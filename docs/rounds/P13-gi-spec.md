# P13-gi · 顶边是**两条线**，不是一条线的两种说法（规格）

## 1. 意图

`docs/liquid-glass.md` §6.140 的 **140-5** 从 P13-fu 起就挂在「需拍板」里，句子是
「同一条顶边在深浅下读成相反的东西」：浅色 `边 216 / 冠 236 / 面 230`、深色
`边 54 / 冠 58 / 面 39`（地面 247 / 14）。看起来像「浅色的顶边是暗描边、深色的是受光边」，
于是唯一的解法被写成「给 E1 的顶边单独一条亮线」，而那会动已落地的 E1 判据。

本轮要证明的不是「哪个值对」，而是**这两条线各有各的活**：

- **分离线**（`Border(1, ControlEdge)`，`theme/theme.go:740` 黑 0.06 / `:867` 白 0.07）：
  它的活是「把面从**地面**上分出来」。地面的极性在两种外观下相反（纸 247 / 夜 14），
  所以这条线的方向**必须**跟着地面反相——浅色更暗、深色更亮。
- **冠线**（`InsetShadow` 顶 1px `LensRim`，`theme/tokens.LitFace`，`theme.go:1239-1243`）：
  它的活是「这条面能被碰」。它压的是**面**，两种外观下都是**亮的**。

所以 140-5 不是一对矛盾的测量，是**把两条线当成一条线**读出来的错觉。本轮的量表把两条线
分开，并把「统一成受光边」这个候选**真量一遍**：它在浅色上只剩 2 级分离（出厂 31 级）。

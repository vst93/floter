# P13-iq · 快捷键控件变化后的焦点归还

意图：快捷键设置在录制、改型、提交、删除和宿主刷新后，键盘仍落在可见且正确的控件上。起点 5013b357；最新 P13-ip 交接优先于任务书旧轮号。

读取为原生设置功能页，面向键盘用户，沿既定轻便液态玻璃。拨盘 2/1/6：稳定布局、即时反馈、原信息密度。功能契约是识别当前绑定、修改正确目标、继续操作和退出。使用 qiaomu-design 打磨模式，已读偏好账本、craft-loop、preflight、chinese-typography，Apple DESIGN 的颜色角色和控件章节。取单一交互蓝的语义、2px 焦点环、8px 控件圆角、1px 边线，保留仓库具体 token。

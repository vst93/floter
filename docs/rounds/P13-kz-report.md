## 偷了什么

本轮按qiaomu-design的已有方向打磨路径，沿用仓库liquid-glass合约，不生成风格选择页、不调用外部模型。

- craft-loop菜单第3项焦点环：保住既有3px外延，活动控件墨完整留在视口内。
- 第4项签名交互：反馈变化后0ms显现一次，之后手动滚动不被持续拉回。
- 第9项滚动细节：保留16px淡边，加3px焦点墨共19px净空；新增高度0px。
- 本轮让界面更轻、更有空间感：原编辑槽与开关保持呼吸距离，新增面层0、阴影0、材质0，不靠加框解决可见性。

菜单五项装饰及外部供体移植不执行：当前任务是已有合约内修bug，用户明确不换方向。保留两阶段的修前/修后实图及四视角检查，未拿五项装饰凑数。

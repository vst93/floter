# P13-bf 规格 · 设置页禁用滑块：唯一一句「为什么」比它的提示还轻

## 意图

透明度组的两条滑块在「这个窗口拿不到背板材质」时是**禁用行**（`sliderRow.disabled`
带一句原因）。这一行里，**说明「为什么按不动」的那句是全行最淡的一件**——
比它上面解释功能的提示还淡，比轨道两端那两个词还淡；而**那个不会动的读数**却和
行名一样重。一行里四件东西的阶梯是**反**的：名字最重、读数几乎同样重、提示一档、
原因掉到提示之下。

为什么现在做：通用队列「状态反馈」的禁用/只读面这一半，`docs/liquid-glass.md`
§6.2b-6 收的是**面**（胶囊/按钮/卡片）与**槽**（字段/开关/列表框）两族，
**滑块的读数**这一格没有账——它是「槽」的一种，却没人量过它的行墨。

## 证据（先量，实测 640×320、真设置页地面，`settingsui.slider` 真函数）

地面（`realPageGround`）：浅 **247** / 深 **14**；卡面（`tokens.Control` 叠在地面上）：
浅 **230** / 深 **39**。

| 位置 | 墨 | 浅 | 深 | 对卡面的重量（浅 / 深） |
|---|---|---|---|---|
| 行名 `Main window opacity` | `t.FontSize+1` / 580 / `TextStrong` | **27** | **237** | 203 / 198 |
| 读数 `47%` | `t.FontSize` / `TextStrong` | **37** | **227** | **193 / 188**（几乎与行名同级） |
| 功能提示 | `t.FontSize` / `TextMuted` | 128 | 133 | 102 / 94 |
| 轴两端 `0%` / `100%` | `Caption` / 500 / `TextMuted` | 129 | 132 | 102 / 94 |
| **原因句**（`TransparencyUnavailable`） | `Caption` / 500 / **`TextTertiary`** | **142** | **110** | **88 / 71**（全行最淡） |
| 轨道（可用） | 框架凹槽 | 209 | 58 | 21 / 19 |
| 轨道（禁用） | 框架 0.5 | 219 | 49 | 11 / 10（§6.2b-6 的半退，**对**） |

同一卡面、同一字阶的候选墨（实测）：`TextStrong` 27 / 237、`TextSecondary` 107 / 154、
`TextMuted` 128 / 133、`TextTertiary` 142 / 110。

**两件事**：

1. 原因句 **88 / 71** 是全行最淡的一件——它比「解释功能」的提示（102 / 94）还轻
   **14 / 23 级**。参考 `emptyState`（P8-b，§4.7）把**陈述**钉在 `TextStrong`、
   把提示钉在 `TextTertiary`：陈述永远比提示重。这一行**恰好反着**。
2. 读数 **193 / 188** 与行名 **203 / 198** 只差 10 级——它是这一行里唯一会动的东西，
   而它现在读起来和行名一样「活着」。§1 的「槽」读法是「整块退一半、内线各留一半」：
   轨道退了（21 → 11 级），**读数一格没退**。

## 落地项

| # | 位置 | 现状 | 应改成 |
|---|---|---|---|
| 1 | `settingsui.go` `slider` 的读数（`row.format(v)` 那行） | 恒 `tokens.TextStrong`（193 / 188 对行名） | `row.disabled != ""` 时退一档到 `tokens.TextSecondary`（117 / 109，对行名 203 / 198 是 86 / 89 级差）——**只有禁用的那一档退**，可用行一个像素不动 |
| 2 | 同函数的原因句（`row.disabled` 那行） | `Caption` / 500 / `TextTertiary`（88 / 71，全行最淡） | `Caption` / **580** / `tokens.TextSecondary`（123 / 115）——它是这一行的**状态陈述**，必须压在功能提示（102 / 94）之上 |
| 3 | 行名 | `TextStrong` | **不动**：它是这一行的名字，行还在、还能读（这一行不是 `Disabled` 子树，框架的 0.5 不适用） |
| 4 | 功能提示、轴两端两个词 | `TextMuted` | **不动**：散文与刻度不属于状态 |

**落地后的阶梯**（对卡面的重量，浅 / 深）：行名 203 / 198 ≫ 读数与原因 **117-123 / 109-115**
≫ 提示 102 / 94 ＝ 轴 102 / 94。三档，两套外观同序。旧值 → 新值：
读数 `TextStrong`（193 / 188）→ 禁用档 `TextSecondary`（117 / 109）；
原因 `Caption`/500/`TextTertiary`（88 / 71）→ `Caption`/580/`TextSecondary`（123 / 115）。

**几何**：字阶与行盒**一个字节不动**（原因仍是 `tokens.Caption`，只换墨与字重）；
`sliderRow.disabled` 只在 Windows-无-vibrancy 时非空（`glassmap.TransparencyAvailable`），
两条滑块的几何与可用态逐像素一致。

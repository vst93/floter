# P13-ex 规格 · 抽屉的满态下沿：这一族最后一把刀

## 意图

终端外观抽屉（`internal/terminalui/drawer.go` 的 `a.drawer`）在 P11-au 变成
滚动容器以后就有了满态（`DrawerScroll.MaxY > 0`），但**两端都没有边**：滚到中间时
网格最后一行在条带下沿（= 窗口底边）被水平切断，墨一点没退。它是「滚动收口」这一族
（§6.16–§6.19、§6.113、P13-as 的满态下沿）里唯一还在刀切的面。

**为什么现在做**：P13-ew 之后通用队列的下一格是「空态满态」。空态一族（P8-b / P13-aj）
与满态的四张面（启动器列表 P13-cf、浮层 §6.113、捕获输出页 §6.114、设置体 §6.16/§6.19）
都已量过并落地；把这一族的清单按面清一遍，只剩终端抽屉这一块没有边。

## 证据（改前，640×280，抽屉溢出 MaxY=54.4）

九档滚动位置（`Y = MaxY·k/10`，k=1..9）上，**窗口最后一行像素**（y=279，抽屉的下沿
就是窗口的下沿）的墨展开度（max luma − min luma，读条带宽度内缩 6px）：

| 外观 | 下沿那一行的最坏值 | 同批帧里边上方那一带的墨 |
|---|---|---|
| 浅 | **147** | 169 |
| 深 | **216** | 217 |

下沿那一行与它上面那一带**同对比**——这就是「刀」。设置体在同一个位置是 219 vs 167
（P13-as），浮层是 11 行空白（§6.113）。

## 落地项

| # | 位置 | 现状 | 应改成 |
|---|---|---|---|
| 1 | `drawer.go` `a.drawer`，条带之后 | 无 | 新增一个 `ui.Box`：`Absolute().Bottom(0).Left(0).Right(0).Height(t.Space(1.5))` + `PassThrough()` + `Material(glass.ScrollEdge{Bottom: true, Background: <不透明的条带面>})` |
| 2 | 面的颜色 | — | `theme.FaceOver(theme.FaceOver(t.Background, panelFill(...)), tokens.Control)`：条带面是 `Control`（0.07 薄罩）压在面板上，而 `ui.Color.Alpha` 是**乘**，把 `Control` 直接交给 `ScrollEdge` 会把那道 0.85 乘成 0.06（§6.17/§6.18 同一条反直觉）；面板自己的面又是调色板底色乘 `CanvasAlpha`，整条链一起压才是不透明结果 |
| 3 | 边高 | — | `Space(1.5)` = 5.4。与条带自己的 `Padding(t.Space(2.5))` = 9 配成一笔账：**软边 5.4 + 净空 3.6 = 9**（`Space(1.5) + Space(1) = Space(2.5)`）。**不按** §6.113 那条「内边距 = 软边 + `Space(2)`」，因为条带的内边距长在高度链上（抽屉高 → 画布高 → PTY 行数），视觉轮不许动它；门于是仍开在几何上（滚到底时 5.4 的边整个落在 9px 的空白里） |
| 4 | 条带的内边距 / 高度 / `MaxY` / 内容位置 | — | **一个字节不动**（pin 里钉 `MaxY` 54.4） |

## 行为契约零改动红线

高度链、键盘模型、会话管理、设置写回、i18n 文案、命令接线：**零改动**。只加一层
画在视口上的面（`PassThrough`，不吃指针），条带与网格的盒子一个字节没动。

# P13-ge 报告 — 禁用的开关仍要说得出它现在是哪一档

- 轮号：**P13-ge**｜分支 `mygo-rewrite`
- 选题：纪律第 **4** 档（通用队列「状态反馈 / 禁用面」格里唯一没被量尺碰过的一格）。
  0-3 档全空的证据见 spec §意图：§6 表无 `未开始` 行、用户实测无新条目、「下轮」注脚全落、
  禁用族的**指针**（P13-fi）与**材质**（P13-s/t/u）两半都已收口。
- 规格 `docs/rounds/P13-ge-spec.md`；合约新增 **§6.150**。

## 这轮为什么让它更轻 / 更有空间感

一枚禁用的开关如果读不出「开 / 关」，那个槽就只是一块灰：**层级还在，信息没了**。
量出来的两件事正是「空间感」的最小单位——轨道离地面还剩 28 ~ 90 级、轨道之间相隔
48 / 51 级、旋钮对轨道 28 ~ 106 级。这些数字此前全是散文（`busySwitchControl` 的注释
「the track keeps the state's own fill」）。这一轮把它们钉成判据，于是「轻」不是形容词：
槽退一层、旋钮还在槽里，**两句话都被一个数字守着**。

## 一、先量（动手前，产品代码一个字节没动）

`toggleFrame` 走产品自己的 `switchControl` + `disabledSwitch`（真设置页地面 247 / 14）：

| 外观 | 禁用-开 轨道 | 离地 | 禁用-关 轨道 | 离地 | 开 旋钮对比 | 关 旋钮对比 | 两帧面积差 |
|---|---|---|---|---|---|---|---|
| 浅色 | (126,160,207) | **83** | (219,219,220) | **28** | 50 | 28 | 384/392 px，最大 79 级 |
| 深色 | (79,99,136) | **90** | (41,41,43) | **27** | 75 | 106 | 384/392 px，最大 139 级 |

轨道台阶 **48**（浅）/ **51**（深）。结论：状态**活着**，这一轮是 **pin 轮**，
不是修缺陷轮——照 P13-fh 的先例，交付的是「这条话以后不会再悄悄失效」。

**量尺陷阱（本轮踩到并修掉，写下来防止下一轮再踩）**：`OFF` 的旋钮在**左**侧。取样点固定取
盒宽的 18% 会直接量到旋钮本身——浅色读出 237、深色读出 148，得出「禁用-关的轨道比禁用-开亮」
这种荒唐结论，并顺手把第二个 pin 误判成红。修法是取样点随状态翻面（`on` 读左三分之一、
`off` 读右三分之一），并且**两个 pin 都用同一条翻面规则**。量尺先自证，再判产品。

## 五、偷了什么（qiaomu-design · `craft-loop.md` 工艺密度菜单）

1. **第 6 项「编辑细节：hairline / 大写字距标签」** → 落成「槽的**离地台阶**必须 ≥ 16 级」
   （实测 28/83、27/90）。一条槽如果没有可读的台阶，它就不是槽，是背景。
2. **第 12 项「材质细节：内边框高光」** → 落成「光熄了、**状态不能跟着熄**」：禁用的面
   （§6.2b-6）熄受光边，禁用的**槽**没有受光边可熄，所以它的判据只能落在**填充与旋钮**上
   ——这正是本轮四条判据的由来。
3. **第 4 项「签名交互：一个足矣」的减法版** → 落成「`busySwitchControl` 的轨道必须与
   同状态的禁用轨道逐值相等（容差 ≤2）」。同一句话不许有第二个说法。
4. **第 5 项「多层染色阴影」** → 复核而非新增：旋钮那层 `0.25` 黑影在 0.5 淡之后仍在
   （浅色旋钮对轨道 28 级是这一族的下限），**故意不加第二层**——加一层只会让旋钮浮出槽。
5. **A2 两轮制** → 第一轮「量」（两张表）与第二轮「立守卫」（两个 pin）在同一工作单元里完成；
   四视角评审见 §七。

## 六、preflight 逐条结论

- **第 0 步 · 偏好账本**：逐条对照 `references/user-preferences.md`。适用项：P-1（禁斜体——
  本轮不加任何字形）、P-5（可读性优先——判据本身就是「还剩多少级」）、P-7（创意不许吃功能契约
  ——状态可辨是功能契约，不是装饰）。P-2 / P-8（先看后选、出预览页）**不适用**：用户已把方向
  钉死（轻便液态玻璃），任务书明令这条自动车道不许停下来等点选、不许出 HTML 预览。
- **A 反 AI 套路**：通过。本轮零新增视觉元素：无渐变、无发光、无斜体、无三等分卡、无紫色
  渐变、无 emoji。唯一新增的是**判据**。
- **A2 进攻三步**：不适用（不是新设计方向，是既有方向上的量尺）。
- **B 设计读取一致性**：通过。三个禁用读法（面 / 槽 / 透明面）与 §1 表、与
  `pointercensus_test.go` 的 14 站点登记表完全对齐；本轮没有引入第四种读法。
  **D2「正文 ≥ 14px」仍不过**——`tokens.Caption` 9.9px / 正文 10.8px 是**沿用**的未决项
  （已在 `.pending-bugs.md`「需用户拍板」，本轮不改；这在本轮的量尺上也有旁证：浅色禁用-关
  旋钮对轨道只剩 28 级，字号再小，这枚旋钮就成了唯一的读数）。
- **C 动效抽查**：通过（有保留）。`busySwitchControl` 带一个转动的 loader，量尺在
  `ui.Preferences{ReduceMotion: true}` 下取样，因此读数与动画相位无关——这一点写在测试里，
  换 ReduceMotion 就会移位，属于**已知**而非**未测**。本轮没有改任何时长/缓动。
- **E 三秒测试**：通过。眯眼看两张图：第三枚（禁用-开）有一块蓝、第四枚（禁用-关）没有，
  3 秒内能分出哪一枚是开着的——这一句正是本轮要的。

## 七、四视角偏执评审（各挑一处最弱）

- **艺术总监**：最弱的是禁用-关那一枚——它在浅色上只有 28 级离地，几乎是一块比纸深一点的
  槽。**不加**装饰补它：这一族只有一道淡可用（§1），加第二层就回到 P13-s 判掉的老路。
- **工程师**：量尺本身曾把 OFF 的旋钮当轨道（见 §一），说明「固定取样点」是危险写法；
  本轮把取样点写成随状态翻面的**函数**，两个 pin 共用同一处。
- **甲方**：三秒看完记住的是「禁用的开关还看得出开关」。功能契约成立。
- **读者**：图上两枚禁用的都淡、都不抢注意力——这是它们该有的样子（§1「退到 z 的下一层」）。

# P13-fv · 满态第一格：会话页 22 条会话，与它下沿那条软边

## 意图

会话页只量过**空态**（P13-fj / P13-fs）与**单行**（P13-ea 的 56 地板）。「很多行」这一态
没有任何 pin，而它正是软边唯一真正干活的那一态。这一轮把满态量实，并修掉量出来的那一个
缺陷：**页尾那 16px 软边淡的不是它脚下的面，是窗口地。**

为什么现在做：P13-fu 报告「仍待」第 2 条（`140-5` 需拍板）给出的替代路径 = 通用队列
「满态」那一半，第一格候选正是会话页 20 条以上的满列表。

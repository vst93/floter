## 八项验收候选

1. Registry下载/解析失败 → 恢复本次包名和版本 → 本地HTTP失败后重新点击派发原请求。
2. Registry权限取消 → 安静恢复本次输入 → 无错误通知、无安装写盘、可重试。
3. Registry等待时重复安装 → 表单忙态和宿主互斥 → 重复点击/直接派发均只有一次网络与审核。
4. 空白包名仍亮着可按 → 禁用面 → Tab跳过、点击不派发，填入包名恢复。
5. Registry提交阶段失败 → 同样恢复本次输入 → 审核后制造磁盘提交失败并重试。
6. Registry安装按钮进入忙态丢焦点 → 焦点回包名输入 → 可继续编辑、Escape按原模型退出，不抢其他字段。
7. 本地安装按钮进入审核忙态后键盘悬空 → 回既有关闭出口 → 取消后Enter能关闭，不自动夺回焦点。
8. 本地选择器失败没有反馈 → 复用宿主警告 → 一次错误一次通知，取消无通知，仍可重试。

仅实际事件变红才算确认。新草稿（含输入后主动清空）不可被旧请求覆盖；该负向保护随恢复一起验，不单独凑项。两项一批先定向检查再commit/push；全轮只做一次最终全门槛。旧V/B/S断言零改，新增Skip零。

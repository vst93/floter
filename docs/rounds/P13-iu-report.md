## 偷了什么

实际读取 qiaomu-design 的 SKILL、user-preferences、craft-loop、preflight、chinese-typography 与 Apple DESIGN 按钮/颜色章节。设计读取为桌面设置面，轻便液态玻璃，拨盘 **3/2/7**。用户已经限定方向，走既有方向打磨；没有调用外部执行器。

- craft-loop **#3 品牌 focus 环**：Apple 的单蓝交互角色与 **2px** focus 映射既有 token。真实整页提示出现/关闭后原开关蓝环仍在，焦点交接 **0ms**。
- **#4 签名交互**：既有明确提交保持一次动作一次写；别名 **179ms 0 次 / 180ms 1 次**，混合批次 **2 次**，失败后可由原入口重试。保存提示沿用 **5000ms**，没有新动画。
- **#6 编辑细节**：沿用 **1px** 发丝与原行密度；驻留过期的 45 秒输入退场，选择器如实显示 **120 秒**；新增常驻说明 **0px**。
- **#12 材质细节**：Apple 的 **8px** 按钮角映射本仓已有控件角；错误接上既有 E2 面及 **1px** 顶边，新增透明叠层 **0**、新增阴影 **0**。

本轮以恢复可用状态为先，不为菜单凑五种装饰。为什么更轻、更有空间感：错误只出现于既有提示面，操作面与焦点不被重建；已结束的驻留输入退出，不占空间。

## Windows round-2 (7 bugs) — NOT started in code
Blocked earlier because pi/tar-codex gpt-5.6-sol hit a daily 429. Nothing was
committed; the published v0.2.1 is intact. Full spec in
`/home/tar/workspace/pi-spec-2026-07-31-b2.md` (and `.md` backup).

Resume with: `pi --provider tar-codex --model gpt-5.6-sol` on the spec, after
`git pull`. All Windows changes must be `#[cfg(target_os = "windows")]`-guarded;
macOS/Linux must stay untouched. Keep i18n (en + zh) if new strings. Do NOT
commit until verified (cargo check, npx tsc --noEmit, npm run build, cargo test).

1. **Window lost its drop shadow (Windows).** `configure_windows_frame` calls
   `set_shadow(false)` to kill the square undecorated border, which also removes
   the float shadow. Keep `DWMWA_BORDER_COLOR = NONE` + `DWMWCP_DONOTROUND`, but
   re-enable the shadow (`set_shadow(true)` / don't call `set_shadow(false)`).
2. **Window auto-hides on drag-release (Windows).** Native non-client drag makes
   the webview lose focus → the `hide_on_blur` handler hides on mouse-up. Arm the
   existing `suppressBlurUntil` guard in the `startDrag` handler before
   `invoke("start_drag")` (e.g. `+600ms`).
3. **Tray right-click menu flashes / can't click (Windows).** The
   `on_tray_icon_event` `TrayIconEvent::Click` handler calls `reveal_saved_mode`
   even on right-click, dismissing the popup menu. React only to LEFT click.
4. **Terminal: first Enter does nothing, needs a second (Windows).** On terminal
   reveal the canvas isn't focused. Call `focusTerminalView(...)` on the
   `floter://revealed` terminal path. Don't break macOS terminal focus.
5. **Window can't be resized (Windows, terminal mode).** DWM frame config may
   strip the sizing border. Ensure `WS_THICKFRAME`/`WS_SIZEBOX` stays when
   `set_resizable(true)`; differentiate terminal (resizable) vs launcher (fixed).
6. **Alt+Space cannot be set as a shortcut (Windows).** The subclass swallows
   Alt+Space unconditionally, so the recorder never sees it. Add a
   `shortcut_recording` flag (AtomicBool / command `set_recording_flag`) that
   lets Alt+Space pass through to the webview *only while recording*, still
   suppressing the OS menu otherwise. Wire `set_recording_flag{on:true}` at
   record start and `{on:false}` at stop (success + cancel).
   **Linux note:** unaffected — the subclass is Windows-only; X11 registers
   Alt(+Shift) combos fine. No Linux code change needed.
7. **FIRST search result can't be launched (all platforms).** Neither Enter nor
   the number shortcut nor click launches the first result; others work.
   Investigate `selectedResultIndex` / action-bar / Enter branching in
   `src/App.tsx` (`runLauncherItem`, the Enter handler ~line 1897, the
   number-key handler, the row click handler) and fix for all platforms.

## BUG: AppImage launch error on AMD + Wayland (EGL_BAD_PARAMETER)
- **Title:** 启动即报错 Could not create default EGL display: EGL_BAD_PARAMETER
- **Repro:** Run the AppImage directly.
- **Env:** CachyOS (Arch-based), AMD RX 580 (Ellesmere), Mesa 26.1.5, Wayland.
- **Tried (all ineffective):** `WEBKIT_DISABLE_COMPOSITING_MODE=1`,
  `WEBKIT_DISABLE_DMABUF_RENDERER=1`, `LIBGL_ALWAYS_SOFTWARE=1`.
- **Root cause:** Known WebKitGTK issue on AMD + Wayland + new Mesa.
- **Fix suggestion:** On EGL init failure, do NOT abort — gracefully fall back to
  software rendering, or add a force-software-rendering switch. This makes floter
  far more robust on that stack.
